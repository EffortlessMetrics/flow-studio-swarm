# Flow Anti-Patterns

## The Rule
- **Mid-flow blocking**: Complete flow, gate at boundary. Don't halt for questions.
- **Scope creep**: If not in plan, not in build. Charters prevent drift.
- **Skipping gates**: No merge without evidence panel check.
- **Premature optimization**: Make it work, then make it fast.

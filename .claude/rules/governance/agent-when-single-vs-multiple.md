# Agent Selection: Single vs Multiple

Spawn for exactly two reasons: **Work** or **Compression**.

## Single Agent When
- Task is focused and bounded
- No conflicting roles
- Context fits in budget

## Multiple Agents When
- Adversarial tension needed (author + critic)
- Different expertise required
- Context would exceed budget (shard)
- Parallel work possible

If neither work nor compression, don't spawn.

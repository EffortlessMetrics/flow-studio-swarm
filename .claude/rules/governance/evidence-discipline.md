# Evidence Discipline

Don't listen to the worker; measure the bolt.

## The Rule
- **Physics** (exit codes, file hashes) beats testimony
- **Receipts** (captured logs, scan results) beats claims
- **"Not measured"** is valid; assumed pass is dangerous

## Evidence Binding
Claims require: `measured: true/false`, `evidence: <path>`, `result: <data>`

If you claim it, point to a reproducible artifact proving it.

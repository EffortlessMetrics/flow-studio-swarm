# Calibration Loop

The system learns from runs, not opinions.

## The Rule
- Flow 7 (Wisdom) extracts signals from completed runs
- Patterns require **3+ occurrences** before action
- Changes are tested against historical runs before deploy
- Monitor for 1 week after deployment

## Loop
Runs → Signal Extraction → Pattern Detection → Propose Change → Test → Deploy → Monitor

# Calibration Signals

Track these to know if the system is improving.

## Primary Metrics
| Signal | Target |
|--------|--------|
| Detour rate by flow | < 20% |
| Human intervention rate | < 5% |
| Average run cost | Trend down |
| Time to merged PR | Trend down |

Regression on any metric triggers investigation, not panic.

# Context Discipline

Intelligence degrades as irrelevant history grows.

## The Rule
- Each step starts fresh (session amnesia)
- Rehydrate from **artifacts**, not conversation
- Disk is memory; chat is ephemeral

## Loading Hierarchy
1. Teaching notes (always)
2. Previous step output (budgeted)
3. Relevant artifacts (on-demand)
4. History summary (if budget allows)

Heavy context loaders (20-50k) are multipliers: one reads, ten benefit.

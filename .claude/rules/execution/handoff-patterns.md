# Handoff Patterns

Right-size handoffs to their purpose.

## Sizing
| Type | Size | Use |
|------|------|-----|
| **Minimal** | <500 tokens | Microloop iterations (critic → author) |
| **Standard** | 500-2000 | Sequential steps (N → N+1) |
| **Heavy** | 2000-5000 | Flow boundaries (Plan → Build) |

## Include
- What I did (actions, terse)
- What I found (key findings)
- Key decisions (and why)
- Evidence pointers (paths, not content)
- What's next (recommendation)

## Exclude
- Full reasoning chains
- Abandoned approaches
- Verbose explanations
- Raw tool outputs (point to files)

## The Rule
- Summarize, point, structure. Never transcribe.
- Pointers over content. Structure over prose.
- Scent trail carries decisions; don't restate in handoffs.

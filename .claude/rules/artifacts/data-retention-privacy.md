# Data Retention Privacy

LLM transcripts may contain PII.

## Mitigations
- 7-day transcript retention (shortest)
- No transcript archival (delete, don't archive)
- Redact before archival if needed

## Deletion Requests
1. Identify runs with requester's data
2. Apply compliance hold
3. Delete artifacts
4. Document in audit log

## 2024-05-18 - Missing :focus-visible on Semantic Buttons
**Learning:** Custom interactive elements (like `.filter-btn` and `.view-toggle button` in `flow-studio.base.css`) may lack explicit `:focus-visible` styles even if they use semantic `<button>` tags, leading to severe keyboard accessibility issues because focus gets lost. Toggle groups (like `.view-toggle`) need special handling with negative `outline-offset: -2px` and `position: relative; z-index: 1;` so focus rings don't clip or overlap under adjacent buttons.
**Action:** When adding or auditing custom UI elements, ensure explicit `:focus-visible` rules (e.g. `outline: 2px solid var(--fs-color-accent, #3b82f6);`) are provided, especially on `.fs-*` components and custom filters. Use negative offset + z-index for grouped buttons.

## 2024-05-24 - Focus States for Toggle Groups
**Learning:** Custom interactive elements, like grouped toggle buttons (`.mode-toggle button`, `.view-toggle button`, `.run-history-filter .filter-btn`), can lack explicit `:focus-visible` CSS rules even if they are semantic `<button>`s, hiding focus during keyboard navigation. Using default `outline` on tightly packed toggle items causes overlapping outline borders that look broken.
**Action:** When creating or auditing custom UI toggle groups, always ensure explicit `:focus-visible` rules are added (e.g., `outline: 2px solid var(--fs-color-accent, #3b82f6);`). To prevent overlapping outlines in these groups, apply a negative `outline-offset` and set `position: relative; z-index: 1;` so the focused item's outline renders fully inside its bounds and on top of siblings.

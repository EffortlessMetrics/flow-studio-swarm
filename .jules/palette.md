# Palette's Journal - UX & Accessibility Learnings

## 2024-05-22 - [Search Clear Button]
**Learning:** Adding a clear button to a search input using pure CSS for visibility (:placeholder-shown) + minimal JS for clearing is a robust, low-dependency pattern. It handles both user typing and programmatic clearing gracefully without complex state management.
**Action:** Reuse this pattern for other filter inputs in the app (e.g. run filters) to improve consistency.

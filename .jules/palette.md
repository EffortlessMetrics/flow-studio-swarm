## 2024-06-13 - Added missing focus-visible styles to buttons
**Learning:** Found that numerous UI buttons, toggles, and controls lacked a `:focus-visible` outline for keyboard accessibility. Many elements like modal close buttons (`.modal-close`, `.selftest-modal-close`), secondary buttons (`.btn-preset`, `.btn-secondary`), and custom UI widgets (`.tour-dropdown-btn`, `.view-toggle button`, `.collapse-toggle`) relied solely on `:hover` styles, which hides focus from keyboard-only users and impacts overall accessibility. This was consistently reproducible across modals, run history, and the canvas sidebar views.
**Action:** Always verify all custom interactive components provide distinct, visible focus indicators matching the established design system tokens (`var(--fs-color-accent, #3b82f6)`) when triggered via keyboard navigation. Use `:focus-visible` rather than generic `:focus` where possible to preserve mouse/pointer UX while ensuring a11y compliance.

## 2024-05-18 - Added Explicit Focus Visible Styles for Interactive Element Outlines
**Learning:** In `swarm/tools/flow_studio_ui/css/flow-studio.base.css`, custom interactive elements (like `.filter-btn`, `.view-toggle button`) lack explicit `:focus-visible` CSS rules despite being semantic `<button>`s, leading to missing keyboard accessibility indicators. Because these elements often act as compact toggle groups, naive application of default outlines can result in overlapping boundaries.
**Action:** When auditing or creating custom UI elements, ensure explicit `:focus-visible` rules are added (e.g., `outline: 2px solid var(--fs-color-accent, #3b82f6);`). For elements acting as toggle groups, use negative `outline-offset` and `position: relative; z-index: 1;` to avoid outline overlapping issues and ensure the focused element's outline appears correctly on top of siblings.

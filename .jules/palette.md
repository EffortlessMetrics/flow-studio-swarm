## 2024-03-19 - Focus States for Custom Toggle Elements
**Learning:** Custom interactive elements like `.filter-btn`, `.view-toggle button`, and `.mode-toggle button` often lack explicit `:focus-visible` CSS rules despite being semantic `<button>`s, leading to poor keyboard accessibility. When styled heavily (e.g. background changes on hover/active without native borders), default focus outlines might be disabled or invisible. For toggle groups, the outline of one button might be clipped or overlapped by siblings if not positioned explicitly.
**Action:** When auditing or creating custom UI elements acting as toggle groups, ensure explicit `:focus-visible` rules (e.g., `outline: 2px solid var(--fs-color-accent, #3b82f6);`) are added. Use negative `outline-offset` and `position: relative; z-index: 1;` to avoid outline overlapping and clipping issues within button groups.

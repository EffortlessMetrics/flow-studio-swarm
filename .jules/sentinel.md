## 2025-02-18 - [Path Traversal in Evolution & Wisdom APIs]
**Vulnerability:** Found unvalidated user inputs (`run_id`, `patch_id`, `artifact_name`) in `swarm/api/routes/evolution.py` and `swarm/api/routes/wisdom.py` being used directly to construct `Path` objects, opening up path traversal exploits using nested directory traversal combinations like `../../../etc/passwd` that bypass base path assumptions.
**Learning:** FastAPI's `TestClient` auto-normalizes path URLs which hides application path traversal vulnerabilities during routing. The API routes themselves didn't explicitly implement `validate_path_component`, assuming directory validation logic further down the stack that was bypassed because the endpoints use naive Path concatenation.
**Prevention:** In API handlers that receive dynamic paths, explicitly invoke `validate_path_component` on variables prior to building filesystem paths, catching `ValueError`s and wrapping them into `HTTPException(400)` to ensure OS-level traversal attacks are intercepted before file I/O operations occur.

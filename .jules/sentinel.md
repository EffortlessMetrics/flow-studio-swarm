## 2025-03-05 - Path Traversal via Composite Strings in JSON Body
**Vulnerability:** A path traversal vulnerability was found in the Evolution API endpoint `apply_evolution_patch_endpoint`. The endpoint expects a composite ID like `run_id:patch_id` in a JSON request body and splits it to resolve file paths.
**Learning:** While framework-level path normalization intercepts simple traversal attempts in URLs, it fails to protect against traversal payloads embedded within composite strings in JSON request bodies (e.g., `{"patch_id": "../etc:something"}`). The payload bypasses router normalization entirely, leading to arbitrary file access or OS-level path traversal when the components are split and processed.
**Prevention:** Application-level component extraction and validation (e.g., using `validate_path_component`) must be applied explicitly to the separated string segments before resolving file system paths. Never trust nested or composite inputs inside request bodies to be safe from directory traversal.

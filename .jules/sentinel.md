## 2025-03-18 - Path Traversal Vulnerabilities in API Routes Bypassing Framework Defenses
**Vulnerability:** Path traversal payloads (e.g., encoded sequences like `..%5C`) within URL path parameters or complex body strings (`"patch_id": "../etc/something"`) successfully reached filesystem operations (e.g., `runs_root / run_id`) in `events.py` and `evolution.py` endpoints, bypassing standard FastAPI automatic route normalization defenses.
**Learning:** Framework-level URL sanitization mechanisms do not inherently protect against payloads intentionally designed to circumvent normalization, especially when values are dynamically mapped or embedded within request payloads. Relying purely on framework-level protections without application-level verification creates systemic blind spots.
**Prevention:** Always enforce explicit, strict application-level validation (e.g., using an allowlist or the `validate_path_component` function) directly on all user-supplied variables *before* they are utilized in constructing internal file paths, irrespective of where they are sourced from in the HTTP request.

## 2025-01-20 - Fix Path Traversal in Database Routes
**Vulnerability:** Path traversal vulnerability in `/api/db/rebuild` and `/api/db/ingest/{run_id}`. The `run_id` parameter was passed directly to `db.rebuild_from_events_safe` without validation, which then constructed file paths using `runs_dir / run_id`. This could allow an attacker to probe for `events.jsonl` files outside the intended runs directory or potentially list directories.
**Learning:** Even internal or "safe" wrappers like `rebuild_from_events_safe` must not be trusted to validate their inputs if they perform filesystem operations. Input validation should happen as close to the API entry point as possible (in the route handler). Using `pathlib.Path` joining (`/`) does not prevent traversal if the right-hand side contains `..`.
**Prevention:** Always validate path components using `validate_path_component` (or similar strict allowlisting) before using them in file path construction. Ensure that validation exceptions are caught and returned as proper HTTP error responses (400 Bad Request) rather than being swallowed or causing 500s.

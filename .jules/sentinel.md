## 2026-02-05 - [Path Traversal in SSE Endpoint]
**Vulnerability:** The `stream_run_events` endpoint in `swarm/api/routes/events.py` directly used the `run_id` path parameter to construct file paths without validation. This allowed potential access to files outside the runs directory using encoded `..` sequences (%2e%2e), bypassing standard routing checks if the client did not normalize the path.
**Learning:** Testing path traversal vulnerabilities effectively often requires bypassing standard client-side path normalization (like that in `TestClient` or `httpx`). Direct unit testing of the handler function with mocked dependencies proved to be the most reliable method to verify the security flaw and its fix, avoiding false negatives due to test client behavior.
**Prevention:** Always apply `validate_path_component` (or equivalent strict allowlisting) to any user input used in file operations, especially path parameters. Do not assume the web framework or client will sanitize path segments.

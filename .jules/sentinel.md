## 2025-03-05 - FastAPI Path Traversal in Nested and Composite Endpoints
**Vulnerability:** The evolution API accepted `run_id` and `patch_id` parameters that were passed to internal path creation logic without validation. Additionally, `patch_id` in the `apply` route accepted composite IDs formatted as `run_id:patch_id`, which bypassed standard framework-level traversal protections and introduced further risks of OS-level traversal attacks when these segments were split and independently trusted.
**Learning:** Framework-level sanitization might not protect composite payloads stringified within JSON request bodies (e.g., `patch_id: "../etc:something"`). Manual, application-level extraction and component validation is strictly required for any part of a user-supplied string that will be used to resolve file system paths.
**Prevention:** Consistently apply `validate_path_component` from `swarm.runtime.safe_paths` at the controller layer on all raw path segments and composite identifier splits before using them in os/pathlib operations.

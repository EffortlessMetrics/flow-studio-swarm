## 2024-05-24 - [Path Traversal in Wisdom and Evolution APIs]
**Vulnerability:** Fast API routes for `wisdom` and `evolution` were passing user-supplied `run_id`, `artifact_name`, and `patch_id` path parameters directly into the filesystem path construction (`wisdom_dir / artifact_name`). This allowed url-encoded directory traversal components like `..%5c` or direct route function invocations to bypass framework routing protection and read or operate on arbitrary files.
**Learning:** Even though FastAPI normalizes `../` in standard web requests, backend file system resolution uses `pathlib` which accepts unnormalized slashes such as `..\\` on Windows or when explicitly passed as arguments from internal logic. Validation must happen at the parameter level within the application before file system operations.
**Prevention:** Always use a central path validation utility like `swarm.runtime.safe_paths.validate_path_component` inside FastAPI routes to strictly allowlist alphanumeric characters, dot, hyphen, and underscore, explicitly rejecting all traversal patterns like slashes and backslashes before they interact with `pathlib`.

## 2025-01-26 - Path Traversal in SSE Endpoints
**Vulnerability:** The `stream_run_events` endpoint in `swarm/api/routes/events.py` constructed file paths using the `run_id` path parameter without validation. This allowed an attacker to supply a `run_id` like `../secret` to access arbitrary `events.jsonl` files on the filesystem, provided they were accompanied by a `run_state.json`.
**Learning:** Even if an endpoint seems to only read files within a specific directory (`runs_root`), unvalidated user input can be used to traverse out of that directory. The existence of `validate_path_component` utility elsewhere in the codebase (e.g., in `RunStateManager`) shows that this was a known pattern, but it was missed in the SSE endpoint, highlighting the need for consistent application of security controls across all endpoints.
**Prevention:** Always validate path parameters that are used to construct file system paths. Use `validate_path_component` or similar allowlist-based validation *before* using the input. Do not rely on `path.exists()` checks alone, as they return True for existing files even if they are outside the intended directory.

## 2024-05-24 - [Path Traversal in Dynamic API Path Endpoints]
**Vulnerability:** Path traversal vulnerabilities identified in `swarm/api/routes/evolution.py` and `swarm/api/routes/wisdom.py`. Path parameters (`run_id`, `patch_id`, `artifact_name`) used dynamically without validation could allow an attacker to navigate the file system outside the intended sandbox using traversal sequences like `..`.
**Learning:** Even internal API endpoints intended for constrained scopes must validate user inputs representing path variables before resolution via `pathlib.Path` or `os.path`. Furthermore, framework-level path normalization (e.g., in FastAPI's `TestClient` or HTTP routing) can sometimes silently hide test validations during regression writing. Thus, tests should call async endpoint functions directly where appropriate.
**Prevention:** Apply `swarm.runtime.safe_paths.validate_path_component` consistently to all dynamically generated or user-provided path parameters before constructing file paths. Additionally, in tests for path validation behavior, manually inject payloads through explicit direct async endpoint invocations rather than depending strictly on standard HTTP client middlewares that may pre-sanitize paths.

## 2025-02-18 - Path Traversal in Events Endpoints
**Vulnerability:** Path traversal vulnerability in `swarm/api/routes/events.py` endpoints (`stream_run_events`, `generate_run_events`, `write_event`, `write_event_sync`) where the `run_id` parameter was directly concatenated into the file path using `run_dir = runs_root / run_id`.
**Learning:** Application-level path components extracted from URL parameters or request bodies must be validated, not just framework-level sanitized. Frameworks (like FastAPI) sanitize `../` relative to the base URL but will pass `../etc/something` when embedded as a URL parameter (e.g., `/{run_id}/events` -> `/../etc/something/events`).
**Prevention:** Always validate and sanitize user-provided file path components using a designated validation function (e.g., `validate_path_component`) immediately after receiving the parameter before any file system operations. When applying this to route parameters, catch the resulting `ValueError` and raise a framework-appropriate error with safe detail.

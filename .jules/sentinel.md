## 2025-03-03 - Fix path traversal in Evolution API
**Vulnerability:** The `get_run_evolution_patches`, `get_evolution_patch_details`, `validate_evolution_patch_endpoint`, `apply_evolution_patch_endpoint`, and `reject_evolution_patch_endpoint` endpoints in `swarm/api/routes/evolution.py` used user-supplied `run_id` and `patch_id` strings directly in file path operations without any sanitization or validation, allowing attackers to perform path traversal.
**Learning:** Even when inputs are expected to be system-generated IDs, they must always be strictly validated when used in file system operations. Relying solely on the presence of a file or directory does not mitigate traversal paths mapped maliciously across the filesystem. In `apply_evolution_patch_endpoint`, composite IDs (e.g. `run_id:patch_id`) require splitting and independent validation of each part.
**Prevention:** Always use `validate_path_component` on path segments derived from untrusted user input before they are appended to root paths using `Path` operations. Enforce these validations systematically across all relevant endpoints within the API router.

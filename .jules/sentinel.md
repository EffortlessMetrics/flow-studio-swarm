## 2025-02-28 - [CRITICAL] Path Traversal in Path Parameters
**Vulnerability:** Fast API path parameters (`run_id`, `artifact_name`, `patch_id`) in `wisdom` and `evolution` APIs were being directly used with `Path()` manipulation without sanitization, leading to directory traversal.
**Learning:** Even though FastAPI routes path parameters dynamically, a client can bypass automatic normalization by using encoded slashes (like `%2F`) or passing arguments if routing permits it, which later gets decoded and directly appended to file paths inside the backend functions like `runs_root / run_id`.
**Prevention:** All user-supplied inputs from Path parameters or requests that are eventually mapped to filesystem paths must be actively validated using a secure sanitization method that rejects anything but strictly safe characters, like `swarm.runtime.safe_paths.validate_path_component`. Do not rely solely on web framework routing mechanisms to normalize out traversal sequences.

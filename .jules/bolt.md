## 2026-01-23 - Defer File Existence Checks
**Learning:** When listing items from a large directory (e.g. 50k runs), checking file existence (`os.path.exists`) for every item is a significant bottleneck, even if the check is fast.
**Action:** Sort candidates by cached metadata (e.g. mtime from `os.scandir`) first, then only perform expensive checks (like file existence or loading content) on the top N results that will actually be returned.
## 2026-06-13 - Optimize Directory Traversal Performance
**Learning:** `pathlib.Path.iterdir()` constructs a new `Path` object for every entry in the directory before filtering can even occur. This adds substantial overhead when iterating over directories with many files, particularly when filtering by type (`is_dir()`) or prefix (`startswith(".")`). By replacing `iterdir()` with `os.scandir()` within a context manager, we leverage `os.DirEntry` objects which inherently cache stat attributes and name properties. We observed a >50% performance improvement (1.9s -> 1.0s) in directory traversal time by applying these basic checks directly on the `os.DirEntry` objects before constructing `Path` objects.
**Action:** Default to `os.scandir()` wrapped in a `with` statement for performance-critical directory traversals or hotpaths when filtering by name or type is needed before constructing `Path` objects. Ensure `OSError` is properly caught when handling possibly non-existent directories.

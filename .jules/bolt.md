## 2026-01-23 - Defer File Existence Checks
**Learning:** When listing items from a large directory (e.g. 50k runs), checking file existence (`os.path.exists`) for every item is a significant bottleneck, even if the check is fast.
**Action:** Sort candidates by cached metadata (e.g. mtime from `os.scandir`) first, then only perform expensive checks (like file existence or loading content) on the top N results that will actually be returned.## 2026-01-23 - Avoid pathlib.Path.iterdir() combined with is_dir() for Large Directories
**Learning:** When navigating large directories and filtering by type (e.g. `is_dir()`), using `pathlib.Path.iterdir()` coupled with `.is_dir()` instantiates an expensive `Path` object and triggers a synchronous `stat()` syscall for every item, creating a significant performance bottleneck.
**Action:** Replace `Path.iterdir()` with `os.scandir()` which yields lightweight `os.DirEntry` objects that cache attributes like `.is_dir()` and `.name`, entirely avoiding the `stat()` syscall and `Path` object creation overhead when filtering.
